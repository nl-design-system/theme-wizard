# `<clippy-token-sample-typography>`

Renders a sample of a typography token. Used to illustrate typography tokens and their concepts in the NL Design System.

## Usage

```js
import '@nl-design-system-community/clippy-components/clippy-token-sample-typography';
```

```html
<!-- standard -->
<clippy-token-sample-typography></clippy-token-sample-typography>
```
