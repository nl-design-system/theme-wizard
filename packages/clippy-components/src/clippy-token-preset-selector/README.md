# `<clippy-token-preset-selector>`

A component that allows the user to select a token preset for a component.

## Usage

```js
import '@nl-design-system-community/clippy-components/clippy-token-preset-selector';
```

```html
<clippy-token-preset-selector></clippy-token-preset-selector>
```
